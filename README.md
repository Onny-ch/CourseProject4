# Сервис управления рассылками

Веб-приложение на Django для управления рассылками, клиентами и сообщениями. Реализована регистрация пользователей с моментальным доступом, роль «менеджер» с расширенными правами, просмотр статистики и запуск рассылок вручную (через интерфейс и CLI).

## Стек

- Python 3.13
- Django 5.2
- PostgreSQL 14+ (по умолчанию)
- Bootstrap 5 для базового UI

## Быстрый старт

```bash
# 1. Клонировать репозиторий (загрузить проект) и перейти в каталог
git clone https://github.com/Onny-ch/CourseProject4.git mailing-service
cd mailing-service

# 2. Создать и активировать виртуальное окружение
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\Activate.ps1

# 3. Установить зависимости
pip install -r requirements.txt

# 4. Подготовить переменные окружения
cp .env.example .env
# отредактируйте .env (секретный ключ, параметры SMTP/кеша и реквизиты PostgreSQL)

# 5. Создать базу данных и пользователя в PostgreSQL (пример)
createdb mailing_service
# либо через psql:
#   psql -c "CREATE DATABASE mailing_service;"
#   psql -c "CREATE USER mailing_user WITH PASSWORD 'strong-password';"
#   psql -c "GRANT ALL PRIVILEGES ON DATABASE mailing_service TO mailing_user;"
# скорректируйте переменные POSTGRES_* в .env под эти значения

# 6. Применить миграции и создать суперпользователя
python manage.py migrate
python manage.py csu

# 7. Запустить сервер разработки
python manage.py runserver
```

Приложение будет доступно по адресу http://127.0.0.1:8000/

## Роли и доступ

- **Пользователь**: управляет только своими сообщениями, получателями и рассылками, видит статистику по своим попыткам.
- **Менеджер**: может просматривать все сущности, блокировать пользователей и отключать рассылки. Для создания группы менеджеров выполните:

```bash
python manage.py create_managers_group
```

Назначьте пользователя в группу «Менеджеры» через админку или командой `manage.py shell`.

## Рассылки и CLI-команды

- Запуск рассылки вручную из интерфейса: перейдите на страницу рассылки и нажмите «Отправить сейчас».
- Запуск из командной строки:

```bash
python manage.py send_mailing <mailing_id>
```

Каждая попытка отправки логируется с результатом и ответом почтового сервера.

## Тестирование и качество

Быстрый прогон тестов и статического анализа:

```bash
python manage.py test
flake8 .
black .
isort .
```

Для измерения покрытия:

Локальный прогон тестов с измерением покрытия (≈92%):

```bash
coverage run manage.py test
coverage report
```

Текущие тесты закрывают основную бизнес-логику, в том числе регистрацию, профили, сервис отправки и ограничения доступа.

## Структура приложений

- `users` — кастомная модель пользователя, регистрация, аутентификация, профиль, управление менеджерами.
- `mailings` — сообщения, получатели, рассылки, попытки, сервис отправки, CRUD-интерфейсы и отчётность.
- `config` — настройки проекта, роутинг, кеширование.
- `templates` — базовый Bootstrap-шаблон, страницы для всех разделов.
- `static` — статические файлы (папка создаётся автоматически).

## Полезные советы

- Для реальной отправки писем настройте SMTP-параметры в `.env` (`EMAIL_HOST`, `EMAIL_PORT`, `EMAIL_HOST_USER`, `EMAIL_HOST_PASSWORD`, `DEFAULT_FROM_EMAIL`).
- При необходимости запустить рассылку через cron или планировщик используйте `python manage.py send_mailing <id>` либо расширьте сервис автоматизацией (например, через `django-apscheduler`).
- Для продакшена переключите `DJANGO_DEBUG=False`, настройте `ALLOWED_HOSTS` и используйте внешний кеш (например, Redis).
